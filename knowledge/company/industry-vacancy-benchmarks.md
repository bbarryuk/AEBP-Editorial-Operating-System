# Industry Vacancy and Days-on-Market Benchmarks

This file exists because AEBP content has paraphrased an industry figure into a different statistic (flagged in review 9313-F02). Before citing any external vacancy figure, record here what it actually measures. That means the statistic type, population, start and end events, and period.

## ShowMojo / PM Trends Report 2026

| Field | Value |
|---|---|
| Figure | **5.1 weeks** |
| Statistic | **Median** days on market (not average) |
| Measures | Days on market in ShowMojo's platform data (listing activity to leased). **Not** the full move-out-to-move-in vacancy. |
| Population | ~1.3 million leased units across all 50 states (ShowMojo platform) |
| Period | **Calendar 2025** (not Q1 2026) |
| Comparison figure | Owners surveyed estimate typical vacancy at **3 weeks**. This is a survey of perception (Harris Poll, n=500 small landlords) and a different measure and population. Don't present the gap as a like-for-like "X% longer" error. |
| Correct phrasing | "ShowMojo's 2025 platform data puts median days on market at 5.1 weeks; owners surveyed estimated about 3 weeks." |

## How this relates to AEBP's own figures

- AEBP 25–30 days = active listing to signed lease (`overview.md`).
- AEBP 37.8 days = move-out to move-in, 79 turns, Aug 2025 to Jul 2026 (`portfolio-performance-2026-07.md`).
- None of these three figures are interchangeable. When comparing them, state the start and end events.
